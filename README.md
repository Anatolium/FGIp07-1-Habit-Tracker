# Трекер привычек (Habit Tracker)

Простое веб-приложение — персональный тренер привычек: ежедневный вопрос,
статистика серий, достижения и мотивационные сообщения.

Стек: Python + Flask, SQLite, HTML/CSS/JavaScript (без фреймворков).

## Возможности

- Ежедневный вопрос «Удалось сегодня выполнить привычку?» с кнопками **Да** / **Нет**.
- Отметку за **текущий день** можно исправить; прошлые дни — только просмотр.
- Статистика: текущая серия дней подряд, общее число успешных дней, лучшая серия.
- Достижения на отметках **7, 21 и 40** дней.
- Короткие мотивационные сообщения после ответа (заранее подготовленные, без внешних API).
- Выбор и изменение привычки, сохранение времени напоминания (без отправки уведомлений).
- Данные хранятся в файле `habits.db` и сохраняются между запусками.

## Запуск на Windows

1. Откройте PowerShell в папке проекта.
2. Создайте виртуальное окружение и активируйте его:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   Если PowerShell блокирует активацию, выполните один раз:

   ```powershell
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   ```

3. Установите зависимости (локально, в виртуальное окружение):

   ```powershell
   pip install -r requirements.txt
   ```

4. Запустите приложение:

   ```powershell
   python app.py
   ```

5. Откройте в браузере: <http://127.0.0.1:5000>

Остановить сервер — `Ctrl + C`.

## Файлы

- `app.py` — серверная логика и API.
- `templates/index.html` — разметка страницы.
- `static/style.css` — оформление.
- `static/app.js` — логика интерфейса.
- `habits.db` — база данных SQLite (создаётся автоматически при первом запуске).
